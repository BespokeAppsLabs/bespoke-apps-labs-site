One page. Nothing scrolls.
Everything opens in place.

The whole site is a single viewport-height console. Six capability panels, a live core, one engagement channel. Selecting anything opens a dialog over the console rather than navigating away — so the visitor never leaves their HQ.

Worth flagging: the logo file contains no gold. Its only two colours are #008F64 green and #161A22 charcoal. The gold carried over from the previous site iteration, and you chose it as the accent before I had the file. It still works — gold chrome around a green mark is a deliberate pairing — but a green-only console is one tweak away if you would rather the site match the mark exactly.

Live green is a state, never decoration — it marks the live clock dot, the current phase, and the focused node. If everything is emerald, nothing is live. Gold carries all chrome: rules, labels, corner ticks, the primary action.

02

Type

Two faces, three jobs
{{t.sample}}
{{t.spec}}
{{t.use}}

The face was identified by measurement, not by eye: glyph widths, x-height and bracket proportions were taken off the logo file and matched against eight candidates. Plus Jakarta Sans 600 came within 2.7% on every metric, and its native < is 0.668 of cap height against the artwork's 0.660 — punctuation that close is not a coincidence. Montserrat, the first guess, was 5.9% off and visibly wider; Poppins was never a candidate, its a is single-storey and the logo's is double. Tracking is -0.03em on the wordmark and 0.6em on the descender line, both measured.

The logo face now carries everything — logotype, headings, panel names, dialog titles and body copy. The editorial serif that ran the headings in earlier drafts is gone: it was a holdover from the previous site and it made the console read as two brands stacked on each other. Two families remain. Jakarta owns anything a person reads as language; JetBrains Mono owns anything read as data — labels, the clock, slugs, table values. Headings step down about 25% in size from the serif sizes, because a sans at the same pixel height reads noticeably larger.

One panel per capability, three a side — so every panel has exactly one node and one wire. The nodes sit in two arcs of three rather than a full ring, each facing the panel it belongs to. Below 1100px the columns collapse to one and the core shrinks to 210px; below 700px, dialogs become bottom sheets.

05

Motion carried over

Nothing new to install
Existing pieceLives inNew role
{{m.k}} {{m.f}} {{m.n}}

The circuit is the whole idea: core → spoke → node → wire → the panel that owns that capability. Hover anywhere on the chain and the whole run lights end to end, so a visitor learns the shape of the studio by moving a mouse. On these artboards the sphere and spokes are drawn with a 2D canvas; in the real build they are three.js, using the existing scene. One <Canvas> fixed behind the console, dpr=[1,1.5], pointer-events none. It pauses while a dialog is open — the field going still is what makes the dialog feel like it took focus. The existing prefers-reduced-motion block in globals.css stays and gains a rule that drops the canvas to a static frame.
